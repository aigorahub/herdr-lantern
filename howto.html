herdr plugin · aigora.session-helper · v0.2.0

Session helper for the team

A 90% Herdr popup that starts your agent CLI. You talk; it runs herdr. Each person picks their own helper and model.

Install the plugin

  1. Need Herdr 0.7.5+ on macOS or Linux, already running and attached.
  2. If you previously linked a local checkout, unlink it first: 
    herdr plugin unlink aigora.session-helper
  3. Then install from GitHub: 
    herdr plugin install aigorahub/herdr-session-helper

Developers can herdr plugin link /path/to/herdr-session-helper instead. Do not link and GitHub-install the same id at once.

Pick your helper CLI

The popup is not a new chat UI. It launches one of the CLIs you already have. That choice is yours; it is not a shared team model.

HelperWhat to installYour helper.conf
Devin Devin CLI on PATH (often ~/.local/bin/devin) HELPER_AGENT="devin". Leave HELPER_MODEL empty. Set HELPER_PERMISSION to smart.
Claude Claude Code as claude HELPER_AGENT="claude". Optional HELPER_MODEL and HELPER_EFFORT.
Codex Codex CLI as codex HELPER_AGENT="codex". Optional model and effort.
Grok Grok CLI as grok (often ~/.grok/bin) HELPER_AGENT="grok". Optional model and effort.

HELPER_SPAWN_KIND is separate: it is the default --kind when the helper starts an agent for your work (usually claude), not the CLI in the popup.

Edit your config

$EDITOR "$(herdr plugin config-dir aigora.session-helper)/helper.conf"
HELPER_AGENT="devin"
HELPER_MODEL=""
HELPER_EFFORT=""
HELPER_CWD="~"
HELPER_SPAWN_KIND="claude"
HELPER_PERMISSION="smart"
HELPER_EXTRA_ARGS=""

Empty HELPER_AGENT picks the first of those four on PATH. Leave Devin’s model blank; launch ignores HELPER_MODEL for Devin and uses ~/.config/devin/config.json.

Open it

  1. In Herdr, press ctrl+b then H (prefix, then capital H — lowercase h still moves focus left). Bind prefix+H to aigora.session-helper.open if it is not already in your config.toml, then herdr server reload-config.
  2. Or from any terminal, after putting this repo’s hsh on PATH: 
    hsh

Quit the helper CLI as usual. The popup closes with it. Script and config edits do not need a Herdr restart — reopen the popup.

What to say

  • “Who is working, blocked, or done?” Inspect-only. It runs herdr agent list and summarizes.
  • “Jump me to the love-spark agent.” Reuse the existing workspace. Unnamed agents use a pane id, e.g. w1X:p1.
  • “Open the image maker repo with claude.” Reuse the workspace and agent if they are already there. Agent slugs: image-maker, not “Image Maker”.
  • “Make a worktree on herdr for branch helper-tests.” herdr worktree create, not a second workspace on the main checkout.

Create / start / focus / close are blocked until you confirm the exact path or target. The helper then reruns with HERDR_HELPER_OK=1. “Clean everything up” should ask which workspaces.
