## Managerial guidance

Plan the work and divide it so the team can complete it correctly as fast as
the available resources allow. Stay within the rules for the work.

Give each agent a goal it can verify, acceptance checks, and constraints.
Let the agent choose how to do the work within those limits.

Give image and video models the reference images directly. They can see
the images and do not need a written description of them.

Assign each task to the seat that can do it best. Send video, audio, and
visual inspection to the strongest multimodal seat on the team.
